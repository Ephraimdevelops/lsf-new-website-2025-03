Civil Registration

Birth Certificate

Registration for children and adults, hospital verification, and late registration certificate.

Required Documents:
• Parent NIDA ID
• Notification of Birth from Hospital
Fee: From TZS 7,000 depending on application scenario
Vital Records Service

Death Certificate

Submit death notification, obtain an official death certificate, and legal confirmation.

Required Documents:
• Hospital Death Report (Burial Permit)
• Deceased ID or NIDA
Fee: From TZS 7,000 depending on application scenario
Public Online Tool

Track Application Status

Check progress of your application online using Application Code and Control Number.

Required Numbers:
• Application Code (e.g: RITA-2026-7842)
• GePG Control Number (e.g: 991080048291)
Fee: Free
Track Status
Government Use

Certificate Verification

Verify authenticity of RITA certificates for use in other government services, employment, education, and legal procedures.

Required Information:
• Certificate Number or Application Code
• Applicant Name and Event Year
Fee: 6,000 TZS for Birth and Death Certificates
Re-Issuance

Duplicate Certificate

Apply for a replacement certificate if the original is lost, damaged, or needs re-issuance for official use.

Required Documents:
• Original Certificate Number or Application Record
• Applicant NIDA ID
Fee: 7,000 TZS for Birth and Death Certificates
Record Update

Certificate Correction

Apply for correction of details on a certificate such as names, dates, or other records after submitting legal evidence.

Required Documents:
• Copy of certificate with error
• Proof documents for correct details (e.g: affidavit / hospital letter)
Fee: 13,000 TZS for Birth and Death Certificates
