# New LSF Website Design System

## Design Philosophy

Based on inspiration from Gates Foundation, CARE, Amnesty International, and other leading organizations, our new design system emphasizes:

- **Clean, minimal design** with generous white space
- **Real photography** showcasing authentic stories and impact
- **Simple, flat design** with minimal shadows and gradients
- **Clear typography hierarchy** for excellent readability
- **Consistent spacing** and grid-based layouts
- **Purposeful color usage** aligned with our brand
- **Accessible, responsive design** that works everywhere

## Visual Style Guidelines

### Colors
- **Primary**: Use our brand primary color sparingly for CTAs and key elements
- **Secondary**: Maintain our secondary color palette but use more strategically
- **Neutrals**: Emphasize whites, grays for clean backgrounds
- **Gradients**: Minimal use, avoid dark/complex gradients

### Typography
- **Headlines**: Clean, bold typography with proper hierarchy
- **Body text**: Readable, well-spaced with good contrast
- **Consistent sizing**: Follow established type scale

### Layout Patterns
- **Grid-based**: Consistent 8-point grid system
- **White space**: Generous padding and margins
- **Card design**: Clean cards with minimal borders/shadows
- **Image placement**: Strategic use of real photography

### Interactive Elements
- **Buttons**: Clean, simple with subtle hover states
- **Links**: Underline on hover, clear color distinction
- **Cards**: Minimal shadow, simple hover effects
- **Forms**: Clean, accessible input design

## Component Design Patterns

### Hero Sections
- Large, impactful real photography
- Clear, bold headlines
- Minimal overlay gradients
- Clean CTA buttons
- Simple stats presentation

### Content Cards
- White background with subtle border
- Real images without heavy filters
- Clean typography hierarchy
- Simple hover states (shadow only)
- Clear CTAs

### Section Headers
- Clean badge/tag design
- Bold, readable headlines
- Supporting descriptive text
- Consistent spacing

### Image Usage
- Prioritize real photography over illustrations
- Show real people and authentic moments
- Avoid heavy filters or overlays
- Maintain aspect ratios consistently

## Implementation Guidelines

### What to Avoid
- Complex gradient overlays
- Heavy shadows and borders
- Complex hover animations
- Dark, heavy backgrounds
- Overcomplicated layouts

### What to Embrace
- Clean, flat design elements
- Generous white space
- Real, authentic imagery
- Simple, clear navigation
- Consistent component patterns

### Responsive Design
- Mobile-first approach
- Consistent spacing across breakpoints
- Readable typography at all sizes
- Touch-friendly interface elements

## Accessibility Standards
- WCAG 2.1 AA compliance
- Proper color contrast ratios
- Keyboard navigation support
- Screen reader optimization
- Focus state indicators

This design system should guide all future website development and redesign efforts.
